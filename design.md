Create a web application for personal investment in Norway.

Users provide amounts of money they are willing to invest each month.

The app

- ask questions related for them
- suggests best suitable funds for them to invest.
- show history and future growth of their investment portfolios with the
  provided answers.

Tech stack:

- Frontend
  - React, Typescript
- Database
  - PostgreSQL

- ML
  - LLMs
  - RAG

- Backend
  - FastAPI
  - Gunicorn
  - Nginx

- DevOps
  - Docker
  - Github Actions
  - AWS
